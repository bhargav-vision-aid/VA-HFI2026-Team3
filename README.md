# VA-HFI2026-Team3
# 🎙️ Indian Sarvam AI TTS Addon for NVDA Screen Reader

This NVDA add-on integrates **Sarvam AI Streaming Text-to-Speech (TTS)** to provide fast, natural, and multilingual speech output.

⚡ Designed with a strong focus on **Indian languages**, this add-on enables real-time speech and translation inside NVDA.

---

## 🚀 Installation

1. Download the `.nvda-addon` file
2. click the file
3. Click **Install** when prompted
4. NVDA will restart automatically

---

## 🇮🇳 Indian Language Support (High Priority)

Sarvam **Bulbul v3** supports major Indian languages including Hindi, Bengali, Tamil, Telugu, Gujarati, Kannada, Malayalam, Marathi, Punjabi, Odia and English.

👉 The system is optimized primarily for **Indian multilingual usage**

---

## 🔑 API Key Setup

This add-on requires a Sarvam AI API key.

* Get your API key from: https://dashboard.sarvam.ai/?from=signin
* Pricing may change — please check the website for latest plans

---

## ⚙️ Settings Panel

Open settings using:

**NVDA + N → Preferences → Settings → Sarvam AI Speech**

---

## 🧭 Available Options

### 🔐 Sarvam API Key

Paste your API key here.

---

### 🌐 Get API Key Button

Opens the Sarvam AI website to generate/purchase API key.

---

### 🌍 Enable Translation (Checkbox)

* **ON** → NVDA speech is translated and spoken in selected language
* **OFF** → Original text is spoken

#### ⌨️ Shortcut:

**NVDA + Shift + T** → Toggle Translation

---

### 🗣️ Target Language (Combo Box)

Select the language from the combo box in which translated speech will be spoken.

* Source language is **automatically detected**

---

## 🎤 Voices (Indic Voices)

Currently supports **6 Indic voices** (may expand in future updates).

* Designed for natural and clear Indian speech output
* Voice switching handled internally based on language

---

## ✍️ Translate Selected Text

### ⌨️ Shortcut:

**NVDA + Shift + Y**

### 🔹 Features:

* Translates selected text into target language
* Automatically copies translated text to clipboard
* Works even if **Enable Translation is OFF**

---

## ⌨️ Customize Shortcuts

Go to:

**NVDA → Preferences → Input Gestures**

Search for:

* Toggle Translation
* Translate Selected Text
