🎉 First Release: Sarvam AI TTS NVDA Add-on v1.0 🔊

This NVDA add-on enables Sarvam AI cloud-based Text-to-Speech inside the NVDA screen reader. It provides natural sounding neural voices for multiple Indian languages using the Sarvam AI TTS service.

🔊 Features

✅ Cloud Based Neural Speech

  • Uses Sarvam AI’s advanced neural text-to-speech engine
  • Produces natural and clear speech output

✅ Multiple Indian Languages

  • Supports several Indian languages including:
  • English, Hindi, Tamil, Telugu, Kannada, Malayalam, Bengali, and Marathi

✅ High Quality Voices

  • Natural sounding AI-generated voices
  • Improved clarity for screen reader users

✅ NVDA Integration

  • Works directly as an NVDA synthesizer
  • Can be selected from NVDA’s Synthesizer settings

✅ API Key Configuration

  • Users can configure their Sarvam AI API key in NVDA settings
  • Required for generating speech from the Sarvam cloud service

🛠 Technical Info

  • Written in Python using NVDA’s Synth Driver API
  • Uses Sarvam AI REST API for speech generation
  • Audio is generated in WAV format and played by NVDA
  • Supports NVDA 2025 and above

📦 Installation

  1. Download the .nvda-addon file
  2. Press Enter on the file
  3. NVDA will ask to install the add-on
  4. Restart NVDA to activate the synthesizer

⚙ Setup

  1. Open NVDA Settings
  2. Navigate to the Sarvam AI Speech settings
  3. Enter your Sarvam API key
  4. Select Sarvam AI TTS as the synthesizer
